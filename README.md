# PinoyCart PWA

## Install on Windows
1. Put these files on a web server (GitHub Pages, Netlify, Vercel, or your own hosting).
2. Open the site in Chrome or Edge.
3. Use the browser's Install / Add to desktop option.
4. Pin PinoyCart to Start or the taskbar.

A PWA must be served over HTTPS (localhost is also allowed for testing), so opening index.html directly from a file may not show the install option.
